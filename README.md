# Vivek Kosigi Portfolio — V3

Static HTML/CSS/JavaScript portfolio with a homepage overview and dedicated project case studies.

## Local preview
Open `index.html` in a browser or use VS Code with Live Server.

## Structure
- `index.html` — homepage
- `style.css` — shared styling
- `script.js` — responsive navigation
- `assets/` — resume and supporting assets
- `projects/` — individual case-study pages

## Pages
- `projects/rv-npu.html`
- `projects/rc-mac-fpga.html`
- `projects/4-bit-alu.html`
- `projects/diff-amp.html`
- `projects/interconnect-research.html`

## Deploy
Upload folder contents to the root of a GitHub Pages repository. Preserve the relative `assets/` and `projects/` paths.

## Accuracy notes
RV_NPU, RV-MAC-FPGA and differential-amplifier pages use public repository information. The interconnect page flags results that need checking against the original plots before final publication. The 4-bit ALU page is a structured draft awaiting its source repository or reports.
