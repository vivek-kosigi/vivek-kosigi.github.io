01 / CIRCUIT OVERVIEW

CMOS differential amplifier

A transistor-level, single-stage CMOS differential amplifier designed and physically implemented in Cadence Virtuoso. It uses an NMOS differential input pair, PMOS active load/current mirror and an NMOS tail current source, producing a single-ended output.
