01 / PROJECT OVERVIEW

RISC-V + hardware accelerators

A lightweight 32-bit RISC-V processor integrated with MAC and single-layer perceptron accelerators. Written in synthesizable Verilog and implemented on a Xilinx Artix-7 FPGA using Vivado.

The design includes a five-stage pipeline (IF, ID, EX, MEM, WB), instruction memory, register file, ALU, MAC accelerator, perceptron accelerator, LED output and an HD44780-compatible 16×2 LCD interface.

02 / VALIDATION

FPGA implementation

  • Functional simulation using XSim
  • Synthesis and implementation in Vivado
  • Timing and power reports reviewed
  • Bitstream generation and FPGA programming
  • Hardware behavior checked using LEDs and LCD
