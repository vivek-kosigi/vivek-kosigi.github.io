01 / PROJECT OVERVIEW

Decoupled CPU–NPU execution

This project studies integration of neural-processing hardware with a RISC-V processor while allowing the CPU and NPU to execute independently. The CPU can continue scalar work while the NPU processes neural workloads instead of remaining idle for the entire computation.

The repository documents RTL simulation, logic synthesis, physical design, post-route analysis, architectural ablation and technology scaling. Reported values are EDA-tool estimates, not measurements from fabricated silicon.
